# GigSim (stand-in)

The instructor's GigSim was not included in the starter kit we received, so this directory holds a
self-built stand-in that follows the brief's description. After seeding it is treated as frozen;
CI checks that nothing under `gigsim/` changes.

- `app.py` — FastAPI REST simulator: jobs, market stats, client histories, Connects, proposals
  (draft → submit, idempotency keys), messages, events, rate limits (429 + Retry-After),
  random 5xx errors, and simulated clients with hidden preferences (`/admin/tick`).
- `seed/` — generated by `scripts/data/build_seed.py` from real Kaggle Upwork data plus labelled
  synthetic additions (see `docs/DATA_CARD.md`).

| Env var | Default | Meaning |
|---|---|---|
| `GIGSIM_API_TOKENS` | `dev-token` | comma-separated bearer tokens |
| `GIGSIM_RATE_LIMIT_PER_MIN` | 60 | per-token request limit |
| `GIGSIM_ERROR_RATE` | 0.02 | probability of a simulated 5xx |
| `GIGSIM_CLIENT_MODE` | `rule` | `llm` = clients decide with an LLM, `rule` = deterministic |
| `GIGSIM_UNPUBLISHED_TAIL` | 200 | stream jobs held back for `/admin/publish` |

Run: `uvicorn gigsim.app:app --port 8081`
